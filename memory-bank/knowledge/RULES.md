# Rules

> 이 프로젝트의 규칙과 컨벤션. 모든 sub-agent가 반드시 따라야 함.

## G-01: 코드 주석은 영어만 사용 (MANDATORY)

**규칙:** 모든 코드 주석(`//`, `/* */`, `///`)은 영어로 작성. 한글 주석 금지.
**이유:** 소스 파일 내 한글은 인코딩 문제 및 빌드 오류를 유발할 수 있음.
**적용 시점:** 코드 작성 또는 수정 시 항상. UI 텍스트(사용자에게 보이는 문자열)는 한국어 유지.

## R-01: 비밀번호는 main 프로세스에서만 비교

**규칙:** 회원 비밀번호는 SHA-256 해시로 `data/runtime/members.json`에 저장하고, 평문 비교는 `electron/main.ts`의 `auth:login` 핸들러와 `vite.config.mts`의 `/api/auth/login` 미들웨어(Node 컨텍스트)에서만 수행한다. 렌더러(React) 코드에는 해시 비교 로직을 두지 않는다.
**이유:** 렌더러 번들에 비교 로직이 들어가면 우회가 쉬워지고, 회원 목록 응답에 해시가 노출될 위험이 커진다.
**적용 시점:** 로그인/비밀번호 변경 관련 코드를 작성할 때 항상. 회원 목록을 렌더러로 보낼 때는 `passwordHash` 필드를 제거한다.

## R-02: 그레이스케일 디자인 토큰만 사용

**규칙:** `src/styles/app.css`의 색상은 흑/백/회색 계열만 사용한다. 삭제·위험 액션 버튼에만 최소한의 붉은 계열을 허용한다.
**이유:** 사용자가 SNS-Reader의 크림톤과 구분되는 "진짜 흑백 minimal" 디자인을 명시적으로 요청함.
**적용 시점:** 새 컴포넌트나 상태(active/hover/badge)에 색을 추가할 때.
